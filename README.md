## Project Summary

This micro-project demonstrates the application of the Heat Equation to 1D image blurring and restoration. The diffusion of pixel intensity along a 1D scan line is modeled using a partial differential equation.

The project uses the Fourier Series solution to analyze how a sharp edge changes over time due to diffusion. Higher-frequency components decay faster, resulting in the progressive blurring of the signal.

Python is used to implement the mathematical model and visualize the signal at different time steps, including:

- t = 0
- t = 0.1
- t = 0.5

The results demonstrate the low-pass filtering effect of the diffusion equation and provide an engineering interpretation of image blurring.

## Objectives

- Model 1D image blurring using the Heat Equation.
- Apply Fourier Series to obtain the analytical solution.
- Study the decay of higher-frequency components.
- Simulate signal degradation using Python.
- Visualize the effect of diffusion at different time steps.
- Understand the low-pass filtering behavior of the Heat Equation.
